# UI MOCK v26：短縮提案を常設表示し、1回で承認

管理者の当日進行に最新の巻き・バッファ短縮案を常設。旧「短縮提案を開く→確認モーダル→承認」を廃止し、表示中の案から「この提案を承認」1回で反映。

- 実績、当日見積、短縮可否が変わると案を自動更新。
- 対象パート/対象時間/現在の見積/短縮後/短縮量、および終了目標・遅れ・吸収可能量・残る遅れを表示。
- 表示だけでは反映しない。承認直前に案が変わった場合は反映せず、最新案の確認を促す。
- 対象なし/遅れなしは状態を表示し、承認ボタンを無効化。承認済みの案を二重適用しない。
- 当日見積だけを更新し、元の予定・実績・演奏時間・開始済み/保護枠を変更しない。
- スマホでも比較表を開かず案を確認可能。参加者表示には提案/承認を出さない。

QA：新規22＋既存291＝313項目成功。常設表示、実績後の自動更新、1回承認、残る遅れ、古い案の拒否、監査、役割、モバイルを確認。
