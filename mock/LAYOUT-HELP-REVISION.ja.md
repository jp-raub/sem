# UI MOCK v11：集計枠の順序、画像サイズ、入力説明

2026-10-11 04:18の依頼を反映。

## 順序修正

原因は、公開設問の集計パネルだけ設定枠の並び替え対象に含まれず、先頭へ残ること。集計が存在する状態を回帰テストに追加。

フェーズ設定 → タイムテーブル → 追加設問の回答状況（公開設問がある場合） → 観覧のみ申し込み → コメント → イベント設問 → イベント限定管理者設定 → 監査ログ。

## ヘッダー画像

PNG/JPEG/WebPを最大10MiBまで選択可能。ブラウザ内保存の上限に配慮し、大きい画像は縦横比を維持して最大2400×1600、約900KiB以下の表示コピーへ縮小/圧縮する。原本は保存しない。超過/破損画像では以前の有効画像を保持。保存前は下書き、最後の保存で確定。既存のアップロード/プレビュー/削除機能は維持。

## 入力説明の外部化

55項目を目的別に定義。曲と進行の時間、開催時刻と準備時間、会場URLとSNS、人数上限と曲登録制限、設問の件数公開と本文公開などを区別する。

- field-help-locales.json：言語とファイルの対応。既定ja。
- field-help.ja.json：日本語の説明。
- field-help.en.json：英語の説明。
- field-help.js：固定項目と安定した意味キーの対応、言語読込/既定言語へのフォールバック。

文言変更はJSONだけで可能。新言語は同じキーのJSONを追加し言語対応表へ登録する。既存の?の位置とホバー/タップ/キーボード動作を維持。管理者が追加した回答欄には説明を付けない。未定義の項目には不正確な汎用説明を表示しない。説明はテキストとして挿入し、HTMLは実行しない。

英語カタログは入力説明のみ。画面全体の翻訳やユーザー向け言語選択UIは今回の対象外。
