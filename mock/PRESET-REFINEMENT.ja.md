# UI MOCK v14：時刻の整列・プリセット名クリック編集

- タイムテーブルの時刻セルと該当列見出しを右寄せし、数字を等幅に表示する。
- サービス編集モードではプリセット名のクリック、Enter/Spaceから既存の編集モーダルを開く。
- 表上の編集・削除ボタンを取り除き、削除は編集モーダル内から既存の確認フローへ進む。
- ドラッグ、上下移動、追加、分類検証、監査ログ、下書き保存・取消を維持する。
- プリセット変更は既存イベントに反映しない。

Chromium/Playwrightによる新規14項目とイベント機能30項目、参加登録21項目、計65項目が成功。通知・認証等の本番サーバー実装や実機テストを完了扱いにはしない。
