# UI MOCK v15：フェーズ管理統一と認証・通知の画面デモ

実認証・メール送信・通知許可要求・Service Worker登録・Push購読/配信を行わない画面プレビューです。架空のデータだけを使用してください。

## 確認方法

- イベント管理の編集モード：カスタムフェーズ名から編集、削除はモーダル内。有効中は削除不可。既定フェーズは変更不可。
- ログイン画面：パスキーの模擬ログイン、招待登録、復旧サンプルの入口。パスワード欄は表示しない。
- 招待登録：情報入力→メール確認待ち→初回キー登録→デモ利用開始。登録途中では通常利用しない。
- 共通メニューのパスキー管理：サンプル一覧、再認証・保存済みメール再確認・追加、最後のキー削除禁止、メール変更のプレビュー。
- 全体管理者のサービス管理：認証状態と理由付き復旧、対象者の同一メール確認/再登録、メール/日次ダイジェストの文面サンプル。特権復旧は案内のみ。
- 共通メニューの端末通知：実API/実許可と模擬状態を区別。有効化/解除、拒否案内、画面内テスト通知。
- イベント管理の通知設定：通知名から編集、モーダル内削除、タイトル/本文/対象、有効/無効、即時/指定日時/相対指定、日本時間の予定プレビュー。監査ログの前へ追加。
- 通知ルールは下書きに反映し最後の保存で確定。候補の種類・対象・既定値は本番の最終仕様ではない。
