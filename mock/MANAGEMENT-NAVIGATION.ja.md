# UI MOCK v31：機能別管理メニュー

ハンバーガーの主メニューを、サービス管理・イベント一覧ページ・プロフィール管理・アカウント管理・通知管理・招待管理・ログアウトの順に整理。サービス管理は既存の全体管理者権限に従って表示。メッセージ/未読は右上に維持し、表示設定/デモユーザー切替は補助操作へ分離。

- プロフィール：アイコン、表示名、読み、対面での呼び、SNS。読みはひらがな（カタカナは保存時に変換）、対面呼びはひらがな/カタカナ。
- アカウント：現在のメールと検証付き変更フロー、既存のパスキー管理を統合。
- 通知：端末の通知許可と、イベント別の通知事項を一画面へ。担当管理者の定義編集は既存の下書き保存/取消と入力検証を使用。
- 招待：登録ユーザーが発行リクエストを登録し、自分に割り当てられたリンクを確認。全体管理者は元の発行/無効化操作と、リクエストへの有効リンク割当を下書き編集。取消は割当を取り消し、保存後に依頼者へ表示。
- サービス管理の招待操作は専用ページへ案内。ログアウトは従来の認証/端末状態の処理を維持。
