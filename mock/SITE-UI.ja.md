# UI MOCK v30：短い項目名・サイトメニュー・サイト名設定

- 入力項目へ必須/任意の短いバッジを表示。検証ルール自体は変更しない。
- 項目名に括弧で付いていた補足（開始基準・任意の意味・画像条件など）を?ヘルプへ移動。既存説明と合わせてホバー/クリック/フォーカスで表示。
