# GitHub Pagesでモックを一般公開する

[英語版（正本）](PAGES.md)

2026-10-10に架空データのモック公開を承認済み。リポジトリ自体の公開範囲は変更しません。実データ・秘密情報・本番バックエンドは公開しません。

## 最初の1回だけ必要な設定

1. リポジトリの Settings → Pages を開きます。
2. Build and deployment → Source を GitHub Actions に設定します。非公開リポジトリやプランの制限でPagesが使えない場合、無断でリポジトリを公開に変更しないでください。
3. デプロイ先の制限でブランチが拒否された場合は Settings → Environments → github-pages で `ui/session-room-mock` をデプロイ可能なブランチとして許可します。他の保護は維持してください。あるいはPR確認後にmainへマージして公開します。
4. Actions → Deploy UI mock to Pages を開き、設定前に失敗した実行があれば Re-run all jobs を選びます。モックブランチへの新しいコミットでも起動します。

モックの更新を `ui/session-room-mock` または `main` にpushすると公開処理が自動実行されます。push起動にマージは不要です。GitHub画面からの手動実行は、通常ワークフローを既定ブランチに入れたあと利用可能になります。

標準の公開先は `https://jp-raub.github.io/sem/ui-mock/` の見込みですが、これは公開成功を確認したURLではありません。実行成功後のgithub-pages環境URLを使用してください。独自ドメインならURLが変わります。

このワークフローはリポジトリ全体のPages成果物をモック用に置き換えます。将来の本番Pages公開と併用する場合は構成調整が必要です。自動更新されるのは公開処理が成功した場合のみです。

## 操作

ログイン画面で参加者・イベント管理者・全体管理者を切り替えます。入力は架空情報のみ。各閲覧者のブラウザ内に保存するモックで、実認証・共有DB・メール・排他制御はありません。
