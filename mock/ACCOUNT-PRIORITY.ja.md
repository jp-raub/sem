# UI MOCK v17：権限タグ・プロフィール閲覧・即時認証リセット

- アカウント一覧は表示名、権限タグ、最終ログインの3列。最終ログインはデモ内のログイン/ユーザー切替時刻、日本時間で表示。不明は記録なし。
- 表示名から閲覧専用プロフィール（SNS・プロフィール設問を含む）、プロフィールページへの遷移、権限管理、認証リセットを開く。
- プロフィール編集は除去。権限変更は通常のサービス下書きと最後の保存/取消を維持。
- 認証リセットは編集モード中も可能。追加確認で理由と管理者再認証の模擬確認が必要。確定直後に復旧モードON、サンプルキー削除、理由付き監査を独立保存。
- サービス設定取消・再読込でもリセットは取り消されず、未保存の権限や他設定を巻き込んで保存しない。復旧完了後の再登録状態も保持。
- 特権保護・プロフィール閲覧制限を維持。実認証・メール送信・セッション失効は行わない。
