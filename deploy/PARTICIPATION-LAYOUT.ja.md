# 参加表とYOUR ENTRYのレスポンシブ配置

固定モック `ui/session-room-mock` の最終CSS（`9cf8b031258fa1c9afe9668f54e61f002c4bce17`）に合わせ、イベント詳細の参加表と入力欄の配置を調整した。

- **1500px以下**：参加表・コメントの後にYOUR ENTRYを縦に配置。入力欄はスクロールに追従しない。
- **1501px以上**：参加表の横にYOUR ENTRYを配置し、入力欄を追従表示。
- 狭い画面では表の中を横スクロールする。ページ全体は横にはみ出させない。
- 曲のアーティスト名は右揃え。所要時間は統合表・専用タイムテーブルとも右揃え・等幅数字で表示する。日時の計算・丸め・保存値は変更しない。
- 案内文は左右位置に依存しない「表」「参加登録欄」とする。

変更は表示のみ。選択・設問回答・送信・枠確保通知・別画面更新への明示確認は既存Participationが引き続き所有する。権限、API、DBスキーマ、CD設定、データ保全方式は変更していない。画面全体がモックと完全一致したことや、別の未実装機能の完了を意味しない。

- `scripts/participation-layout-checks.cjs`：native認証済みの実イベント画面を使用。390／768／960／961／1200／1500／1501／1920px × ライト／ダークで縦積み／横並び、追従解除、表内スクロール、ページ幅、文字整列を検査。同じ未保存選択・回答を維持したまま幅変更する。テーマ属性の一時変更は表示検査用であり、個人設定保存の試験ではない。
- 上記は既存の全体受入fixtureから呼び出し、既存の保存・競合・枠確保モーダル・専用ルート・データディレクトリ復元検査を置き換えない。
