# Theme catalog persistence (core only)

The catalog is persisted in `ThemeCatalogEntries`. The one-time EF migration creates the table and inserts the ten approved defaults from the pure theme-value library. Defaults are not reseeded at application startup, so later administrator edits are preserved. Existing application tables and rows are left intact.

`CoreFoundationService.ReadThemeCatalogAsync` requires a live authenticated actor (enabled account, current security stamp, and non-revoked session) and returns only ID, name, four canonical colors, built-in marker, and row version. Any authenticated actor may read. `AddOrUpdateThemeAsync` additionally requires a global administrator; event-manager status is not sufficient. New IDs are generated by the server. Updates require an exact ID and expected row version. Built-in themes may be edited, but their built-in marker cannot be changed. Validation and database checks enforce lowercase ASCII kebab IDs, bounded names, uppercase `#RRGGBB` storage, and nonnegative row versions.

There is intentionally no delete API. Deletion must wait until selection references and in-use protection exist. No theme-selection API or preference fields are included.

**Scope:** this is catalog storage and core administration only. Themes are not yet selectable or rendered in the application. This is not a production-completion claim. The catalog's default values continue to follow the existing mock IDs; no production user-facing theme behavior is implied.

## Verification

Run `dotnet run --project tests/Sem.ThemeCatalogChecks` from the repository root. The synthetic migrated-SQLite checks configure Identity schema version 3 exactly as the application/design-time factory does; they preserve an existing synthetic passkey row as well as event/profile/settings data, validate snapshot parity, authorization, constraints, row versions, audit atomicity, read-only behavior and one-time seeding. No migration warning is suppressed and no existing Identity model metadata is removed to accommodate a test fixture.
