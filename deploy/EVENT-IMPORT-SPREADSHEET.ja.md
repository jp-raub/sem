# イベント取込：Googleスプレッドシートの公開CSV

## 動作と範囲

既存のイベント取込画面から、匿名で公開されているGoogleスプレッドシートを明示操作でCSV取得し、既存のCSV入力欄へ読み込めます。Googleへの取得はブラウザーから直接行い、読取だけではプレビューや追記を行いません。このInteractive Server画面では、URL入力イベントでURLがBlazor Server回路へ送られ、取得したCSVは単一のSignalR文字列メッセージではなく、ストリーム型JS interop（`IJSStreamReference`）で回路へ転送します。URLとCSVはページ／回路の一時メモリ上で処理し、データベース、ブラウザー保存領域、アプリケーションログには保存しません。プレビューまたは追記を明示実行すると、既存のアプリ内エンドポイントへCSVを送信します。管理者は読み込んだ内容を確認し、既存のプレビューを実行してから、別途確認して追記します。

HTTPSかつホストが厳密に `docs.google.com` のURLのみ受け付けます。スプレッドシートの編集／エクスポートURLまたは公開用 `pubhtml`／`pub` URLに対応します。通常のシートは `/spreadsheets/d/{id}/export?format=csv&gid={gid}`、公開シートは `/spreadsheets/d/e/{id}/pub?output=csv&gid={gid}` に正規化します。タブIDがなければ `0` を使用します。`#gid=...` を含め、`2147483647` 以下の10進数 `gid` に対応します。既知の共有URL装飾 `usp=sharing` と `usp=drive_link` は破棄します。重複パラメーター、未知のクエリー／フラグメント、認証情報、既定以外のポート、エンコード／パストラバーサル経路、別ホスト、別スキームは拒否します。任意のクエリーパラメーターを転送しません。

ブラウザーからCORSで取得し、認証情報を省略し、リファラーとキャッシュを無効化し、リダイレクトを拒否して15秒で中断します。応答は成功したCSV／テキスト形式でなければならず、リダイレクトやHTML／ログイン画面は失敗扱いです。ブラウザー側でContent-Lengthとストリームの両方を1 MiB以下に制限し、UTF-8を厳格にデコードします。取得から転送完了までのキャンセル上限は25秒です。ホストのSignalR／JS interop設定が実用上の上限をさらに下げる場合があるため、対象ホストで1 MiBまでの転送を検証する必要があります。入力されたURLをそのまま取得することはありません。サーバー側のGoogle取得／プロキシは存在しないため、サーバー側URL取得／SSRF経路を追加しません。

取込状態で画面遷移が禁止されている間は、所有者数で管理するdocument capture guardが、同一オリジンへの通常の無修飾プライマリークリックによるリンク移動を止めます。最後の所有者が警告を解除するとリスナーを解除します。修飾キー付きクリック、プライマリー以外のクリック、別のブラウジングコンテキストを対象にするリンクは妨げません。このクリックガードはUI上の保護であり、汎用的なナビゲーションロックではありません。プログラムによる遷移（グローバルなBlazorナビゲーションAPIの直接呼出しを含む）は回避できます。強制再読み込みやタブ終了ではメモリ内の作業を失う可能性があり、既存の終了時警告を引き続き表示します。

## 制限と代替手段

選択したタブがGoogleから匿名でCSV取得可能で、ブラウザーがクロスオリジン応答を許可する場合に限り動作します。Googleログイン、OAuth、認証済みセッションが必要なシートには対応しません。CORS制限やGoogle側リダイレクトによって取得できない場合もあります。Googleへ認証情報、APIキー、Cookie、認証用パラメーターを要求／送信しません。URLとCSVは一時的なBlazor Server回路メモリを通りますが、データベース、ブラウザー保存領域、アプリケーションログには保存しません。Google取得自体はサーバー経由ではありません。既存のローカルファイル／貼り付け経路はストリーム型interopへ変更しておらず、従来のSignalR／文字列メッセージサイズ制限を受ける可能性があります。この変更ではこれら別経路の制限は解消しません。取得失敗時は既存のローカルCSVファイル選択または貼り付けを利用でき、以前のCSV入力は保持します。新しい取得を始めると以前のプレビュー／確認を直ちに無効化しますが、自動でプレビューや追記はしません。

## チェック

`node scripts/event-import-spreadsheet-checks.cjs` でURL正規化／拒否、モック取得ポリシー、サイズ上限、Content-Type、HTML、UTF-8、リダイレクト、タイムアウト、所有者単位のナビゲーションガードを決定的に検査します。テストはモック応答のみを使い、Googleへの接続や実シートとの互換性を主張しません。実ブラウザー統合と新規 .NET／CI 検証は親側で行います。
下書き保護中も、固定経路の認証付きサンプルCSV添付はダウンロードできます。JavaScriptはUTF-8バイト配列を返し、BlazorのIJSStreamReference戻り値変換がストリーム参照を生成します（手動で二重ラップしません）。親側の合成プロバイダー応答を使う実ブラウザー試験では64KiB／1MiBの転送と回線エラーなしを確認しました。実Google接続成功の主張ではありません。
