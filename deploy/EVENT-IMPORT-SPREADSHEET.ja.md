# イベント取込：Googleスプレッドシートの公開CSV

## 動作と範囲

既存のイベント取込画面から、匿名で公開されているGoogleスプレッドシートを明示操作でCSV取得し、既存のCSV入力欄へ読み込めます。ブラウザー内だけで行う読取専用の入力手段であり、取得だけでプレビューや追記は行いません。管理者が読み込んだ内容を確認し、既存のプレビューを実行してから、別途確認して追記します。URLとCSVはページ／コンポーネントのメモリ内に限り、ブラウザー保存領域、アドレスバー、ログ、サーバー要求には出しません。

HTTPSかつホストが厳密に `docs.google.com` のURLのみ受け付けます。スプレッドシートの編集／エクスポートURLまたは公開用 `pubhtml`／`pub` URLに対応します。通常のシートは `/spreadsheets/d/{id}/export?format=csv&gid={gid}`、公開シートは `/spreadsheets/d/e/{id}/pub?output=csv&gid={gid}` に正規化します。タブIDがなければ `0` を使用します。`#gid=...` を含め、`2147483647` 以下の10進数 `gid` に対応します。既知の共有URL装飾 `usp=sharing` と `usp=drive_link` は破棄します。重複パラメーター、未知のクエリー／フラグメント、認証情報、既定以外のポート、エンコード／パストラバーサル経路、別ホスト、別スキームは拒否します。任意のクエリーパラメーターを転送しません。

ブラウザーからCORSで取得し、認証情報を省略し、リファラーとキャッシュを無効化し、リダイレクトを拒否して15秒で中断します。応答は成功したCSV／テキスト形式でなければならず、リダイレクトやHTML／ログイン画面は失敗扱いです。Content-Lengthとストリームの両方で1 MiBに制限し、UTF-8を厳格にデコードします。入力されたURLをそのまま取得することはありません。サーバー側の取得／プロキシは存在しないため、サーバー側URL取得／SSRF経路を追加しません。

## 制限と代替手段

選択したタブがGoogleから匿名でCSV取得可能で、ブラウザーがクロスオリジン応答を許可する場合に限り動作します。Googleログイン、OAuth、認証済みセッションが必要なシートには対応しません。CORS制限やGoogle側リダイレクトによって取得できない場合もあります。Googleへ認証情報、APIキー、Cookie、認証用パラメーターを要求／送信しません。取得失敗時は既存のローカルCSVファイル選択または貼り付けを利用できます。以前のCSV入力は保持します。新しい取得を始めると以前のプレビュー／確認を直ちに無効化しますが、自動でプレビューや追記はしません。

## チェック

`node scripts/event-import-spreadsheet-checks.cjs` でURL正規化／拒否、モック取得ポリシー、サイズ上限、Content-Type、HTML、UTF-8、リダイレクト、タイムアウトを決定的に検査します。テストはモック応答のみを使い、Googleへの接続や実シートとの互換性を主張しません。実ブラウザー統合と新規 .NET／CI 検証は親側で行います。
