# 手動Pushの明示429からの回復

WebPushの明示429はレート制限による未受付として扱い、応答喪失／タイムアウト／ネットワーク／408／5xxと区別します。同じ永続配信をPendingへ戻し、将来の新しい占有でだけ再試行。不明結果Unknownの自動再送は追加しません。

最早再試行は、ローカル指数待機と有効な単一Retry-After（秒数／HTTP日時）の遅い方です。秒未満の応答時計は切上げて早期再試行を防ぎます。欠落／不正／複数／過去のヘッダーではローカル待機を使います。極端な有効秒数は最大寿命を超える値へ制限して終端化するだけで、待機短縮による早期送信には使いません。元の受付＋600秒の期限以後ならExpiredとし、受付印／期限を延長しません。合計5試行・現在の占有トークンを維持し、毎回I/O前にアカウント／閲覧／参加／端末／セッション／有効化を再確認。生ヘッダー／応答は保存・ログ出力しません。

DB移行・DI／ワーカー／HTTP登録・有効化・実Push先接続・ボックス変更・DXP変更・新配布・マージなし。配信部品の合成試験を60項目へ拡張し、秒数／日時／秒未満／1900年の過去／不正値、期限一致／超過、試行上限、参加解除、同時再試行を含めます。送信先は偽物／メモリ内HTTPだけで、全回帰／CIも実機受入とは別証拠です。
