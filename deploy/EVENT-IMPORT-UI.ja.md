# イベントCSV取込UI

## 範囲

`/workspace` のイベント管理一覧から、管理者は `/events/{id}/event-import` を開けます。UTF-8 CSVをファイル選択または貼り付けで入力できます（最大1 MiB）。認証済み `event-import-context` エンドポイントから現在のイベント・アクター・タイトルを取得し、プレビューと追記の全要求でアクターを固定します。ブラウザー状態自体は認可の根拠ではなく、サーバー側でも現在の認可と期待アクターを再確認します。

プレビューは読取専用です。行ごとの状態・エラー、全体エラー、追加・スキップ件数、追記後の終了予定、予定終了超過を表示します。有効なプレビューへの明示確認が必要で、超過が正の場合は別の超過確認も必要です。追記は既存の原子的な `event-import-apply` 操作と受付票／再生契約を使用します。追加対象だけを追記し、既存行は更新しません。

## 安全性と結果不明時の復旧

- ファイルはデコード前にバイト数を制限し、fatal UTF-8デコードを行います。貼り付けテキストも不正なサロゲートと同じバイト上限を検証します。
- CSV、プレビュー、凍結した操作、受付票はコンポーネントのメモリ内だけに保持します。ブラウザー永続化、CSV本文のログ記録、外部URL取得、自動再送は行いません。
- 確認後に正規形の小文字GUIDを一度だけ生成します。イベント、アクター、版、フィンガープリント、CSV、確認フラグを保留操作に固定します。
- 通信エラー、サーバーエラー、不正な成功応答は結果不明として扱います。同じ凍結済み操作を明示的に再試行でき、新しい操作で置き換えることはできません。初回の確定した400/409では操作を破棄し、新しいプレビューを要求します。先行要求が結果不明なら、後続の400/409でも保留操作を破棄しません。403では入力画面を隠して操作IDを保持します。同じアクターで再認証してから結果を照合してください。
- 未送信入力または未解決操作がある間は、内部移動を止め、外部移動・再読み込み時に警告します。強制再読み込みではメモリ内の入力・操作情報が失われる可能性があります。結果不明時は再読み込みや画面終了を避けてください。
- CSVの値とエラーは通常のエスケープ済みテキストとして表示します。キーボードフォーカス表示と、狭い画面でも操作できるタッチサイズのコントロールを用意しています。

## 検証と制限

`tests/Sem.EventImportComposerChecks` は、プレビュー／確認ゲート、超過の個別確認、操作IDと入力の固定、再試行・後続拒否後の結果不明保持、受付応答検証、新規操作への明示的リセット、確定競合後の再プレビューを検査します。この変更では .NET ビルド、CI、実ブラウザー受入の完了を主張しません。共有HTTP作業の停止後に専用チェックと親側統合ビルドを実行してください。本番デプロイは行っていません。外部スプレッドシートURLは取得せず、ローカルCSVファイルまたは貼り付け入力を使用します。
