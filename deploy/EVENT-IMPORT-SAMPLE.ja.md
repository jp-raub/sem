# 認証付きCSV取込サンプルのダウンロード

認証済みのイベント管理者がイベント用のひな形CSVを取得する、読取専用Core経路を追加します。イベントデータの取込・変更は行いません。

## HTTP契約

- `GET /api/core/event-import-sample?id=<event-id>` はUTF-8 CSVを `text/csv; charset=utf-8` で返し、固定の添付ファイル名 `event-import-sample.csv` を使用します。
- `id` クエリはちょうど1つで、空であってはなりません。現在のCookie principalを既存の `ParticipantEvent` で認可し、イベント管理者またはワークスペース管理者だけが取得できます。要求内で指定されたactorは信用しません。
- `POST` その他のGET以外のメソッドは本文処理前に `405` を返します。GETにCSRFトークンは不要です。
- ハンドラーが処理するGET／POST応答に `Cache-Control: no-store` と `X-Content-Type-Options: nosniff` を付けます。

## ひな形と安全性

固定列は `Kind,Title,Artist,Duration,Prep,Parts` です。無害な固定モック値として、曲（4:30、準備0:30）、進行（10:00）、もう1曲（1:02:03、準備0:00）を例示します。表現可能でスプレッドシート数式安全な有効イベント内パート定義があれば、安定順 `(SortOrder, Id)` の先頭候補を両方の曲行で使用します。カンマや引用符はCSVとしてエスケープします。

定義名はトリム済みで、UTF-16コード単位で1～40文字、先頭が英字または数字、かつパイプ・CR・LF・制御文字を含まない場合に限り候補になります。通常のイベント定義上限に合わせ、現在の定義を安定順で最大100件まで調べます。実際の定義名を書き換えず、数式として解釈される先頭文字を避けます。候補がなければ固定ヘッダーと進行例だけを返し、パート名を捏造しません。既存の曲・イベント・トークン・ユーザー等の記録は出力しません。

この経路は書込・監査記録・取込・履歴修復を行いません。ひな形のダウンロードは取込ではないため、取込適格性／履歴チェックを意図的に適用しません。現在の取込履歴・計画編集可否・重複キーその他のプレビュー／確定適格性は評価せず、後続のプレビュー／取込が受理される保証にはなりません。現在のイベント認可と有効なイベント内パート定義の読取だけを行い、外部取得・ブラウザー画面・配布への副作用はありません。
