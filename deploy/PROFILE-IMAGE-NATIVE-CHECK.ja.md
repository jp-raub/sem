# プロフィール画像のネイティブ実行環境検査

英語正本: PROFILE-IMAGE-NATIVE-CHECK.md。

画像デコーダーにはネイティブ部品があるため、ホスト上のビルド成功だけでは配布コンテナーで処理できる証明になりません。

`dotnet Sem.Web.dll --profile-image-self-test` は引数がこの1つだけの場合に動く検査コマンドです。内蔵の2ピクセルPNGをメモリ内で正規化し、配布設定・移行・HTTP・DBアクセス・通知ワーカー開始より前に終了します。画像パス・URL・ユーザーID・業務操作を受け付けません。失敗時は非0終了し、画像データではなく例外の型だけを出力します。

統合スクリプトは破棄可能なネットワーク隔離コンテナーの起動確認後に実行し、20秒で打ち切ります。結果は `verification/profile-image-native.log` へ保存します。画像機能がない過去ソースでは省略します。本番配備やユーザー画像の受入検証ではなく、専用サービス／HTTP／ブラウザー検証も必要です。

ビルド済みアプリイメージでの実行例:

```sh
docker run --rm --network none sem:check --profile-image-self-test
```
