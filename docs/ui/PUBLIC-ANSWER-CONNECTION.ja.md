# 公開回答集計の参照接続

## 範囲と基準

要件F07・U07・D04・T02／T03。固定mock `9cf8b031258fa1c9afe9668f54e61f002c4bce17` の最終ラッパーを基準に、イベント詳細のタイムテーブルとコメントの間へ公開回答状況を接続する。171資産は変更しない。

- YES／NO：有効なYESとNOの回答者数を分母に横割合帯、四捨五入の整数%、人数を表示する。未回答・不正値は分母へ足さない。
- 本文公開の自由記述：trimした同じ回答ごとの人数を、最多群を100%とした棒と回答ラベルで表示する。人数尺度でありYES／NOの割合と混同しない。
- 本文非公開の自由記述：空白だけの値を除いた回答者数と回答者名だけ。本文をSQL結果列・DTO・DOMへ取得しない。Unicode空白も未回答として除く。
- 公開中・未停止・未削除の使用設問だけを、保存順／ID順で扱う。0件と取得失敗を分ける。

固定mockの最終グラフには表の入口がない一方、要件U07は表確認も維持するため、**グラフの骨格・色・尺度を変えず**下部へ「表で回答状況を確認」の補助開閉を置く。これは意図した製品補助状態で、最終mockとの全パネル高さ一致は主張しない。グラフ各要素の寸法とスタイルは別途厳密比較する。表も同じ最小公開DTOだけを使い、新しい情報を露出しない。

## 認可・保存境界

独立した匿名APIは作らず、既存 `GET /api/ui/events/{id}` の現本人・失効・イベント権限を確認した同一read snapshotから `publicAnswers` を返す。表・グラフ・回答者はメール、Credential ID、公開鍵、認証stamp、私的回答、受付情報を含まない。参照はDB／WAL・監査・履歴を変更しない。

回答者のプロフィールリンクは通常の `#/profiles/{id}`。リンク先の現在認可を独立して確認し、回答者であることから新しいプロフィール閲覧権を付与しない。名前・回答ラベル・設問は文字としてエスケープする。

## 操作・状態

- PCホバー、touchタップ、キーボードフォーカス／Enterで回答者を表示する。
- 外側ポインター操作・外側へのフォーカス・Escape・画面移動で閉じる。閉じた後のタップは1回で再表示し、別群へ切り替えられる。
- 固定mockの回答者CSSはpointer-events:noneだが、製品では生成した回答者パネルだけautoへ補い、内部リンクを操作可能にする。内部リンクへ渡る隙間は短い遅延で保護し、リンクへのフォーカス中は閉じない。Escapeで内部から閉じた場合は起点へ戻し、その復帰を新しい開く操作にしない。
- 既存7.5秒再取得で公開解除・失効を反映する。画面切替後の遅延応答を捨て、取得失敗／401／不正DTOでは古いグラフ・回答者表示を消す。

## 未接続と限界

既定公開配置はdemo。実データの公開設定変更・設問回答の保存・保存直後の同ブラウザー再描画は、書込接続時の後続範囲。本変更の参照回帰で完了したとはしない。実volume・実鍵・メール・Pushへ接続しない。

集中検証は `tests/Sem.PublicAnswer.Checks`、`scripts/public-answer-browser.cjs`（既存の実製品合成HTTPS検証から実行）。合成DBでSQL結果列からの私的本文除外、DB／WAL不変、現認可を検査し、同じ合成値の固定mockと4幅×明暗のグラフを比較する。実touch／キーボード／プロフィール遷移・遅延・失敗・公開解除を検証する。全UI・物理認証器・全業務機能の受入証拠にはしない。
