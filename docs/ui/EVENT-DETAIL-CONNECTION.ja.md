# イベント詳細：固定UIへの参照接続

## 範囲と正本

Notionの要件正本を変更せず、採用mock `9cf8b031258fa1c9afe9668f54e61f002c4bce17` の最終ラッパー適用後を画面基準とする。171の正本資産・CSSは変更しない。既定公開配置はdemoのまま。明示実認証モードだけに概要・予定表・現在名簿・公開コメント・認可済みヘッダー画像の参照を接続する。実DB・鍵・私有設定の有効化作業は含まない。

参加登録・枠選択・保存・編集・コメント投稿・プロフィール・受付・通知・当日進行は未接続。操作を無効化するか、その旨を案内する。旧画面や模擬成功を製品へ戻さない。

## 読み取り契約

- `GET /api/ui/events/{id}` と `/header` の各要求で本人・認証状態・失効・現DB管理者・担当・実効フェーズを同じSQLite読取snapshot内で再確認する。担当外非公開と欠落は同じ404、認証失効は401。queryは400、非GETは405。no-storeは既存の製品API共通境界を使う。
- cache、割当、監査、取込履歴を更新しない。既存77モデル・43 migrationは変更しない。欠けた旧タイムパートを推測生成せず、表示不能な保存データは422とする。
- 私的設問・回答、メール、認証情報、監査詳細、受付メモをDTOに含めない。現割当と観覧を本人単位で統合し、演奏者との重複観覧は二重に数えない。登録履歴から現在の名簿を復活させない。
- 旧main `812b2784212e9015ecbbce31280e48cb0bc65e84` の独立した時刻計算・期間表示・本文無害化・会場リンク判定のみ再利用。旧Razor・CSS・大きな保存サービスは移植しない。
- 開催日時を基準に開場行を導出し、曲／進行を秒で連鎖する。準備nullはイベント値継承、明示0は0。丸め対象は準備・演奏開始のみ。容量0も有効な既存値として保持する。
- 未使用のパート列は固定mock同様に非表示。既存の同種複数枠は同じセル内でそれぞれ保持し、勝手に統合・削除しない。

## 表示・リソースの境界

本文はサーバーの共通無害化部品を通す。HtmlSanitizer 9.2.1039とMarkdig 1.4.1を固定し、Markdown生HTMLを無効化、能動要素と外部画像を除去、安全なHTTP(S)リンクだけを許す。名前・コメントは文字として挿入し、無害化済み本文専用箇所以外でHTMLとして扱わない。不明な本文形式は文字列表示。

本文1MiBは変換資源の防護上限で、業務要件としての文字数制限ではない。超過時に黙って切り捨てない。画像は認可後、既存の正規化PNGに限定して1MiB・PNG/IHDR・保存寸法1〜1600と実ヘッダー寸法の一致を検査する。完全な画像再デコードやアップロード・変換を追加したわけではない。

タブは本人×イベントに紐付く選択値だけをsessionStorageの `sem-event-tabs-v1` へ保持する。メール・名前・DB内容・認証情報は保存しない。ARIA、矢印／Home／Endとフォーカスを維持する。

表示中の詳細は7.5秒間隔で再取得し、非表示・ダイアログ中・並べ替え操作中は抑止。古い要求を中断し、失効／エラーで前の本文・画像を消す。画面離脱時にはダイアログ本文も消す。参照専用180要求／分／送信元IPのresource policyを認証試行制限と分離する。この値は業務SLOを保証しない。

## 検証の意味

合成DBの認可・失効・非公開・無害化・画像・時刻境界・最小DTO・DB/WAL不変を集中検証する。実製品HTTPS＋仮想認証器と固定mockへ同じ合成データを入れ、4幅×ライト／ダークで主要DOMの配色・書体・余白・列構成と横はみ出しを比較する。全面pixel一致や全端末の保証ではない。

初回のWAL存在前提のテストと、固定mockが隠す未使用列を表示した実装は、統合前に修正して新規DBから再実行した。失敗試行を成功に流用しない。公開ビルド照合は応答版とreadinessの証拠で、実volumeの機能有効化・全レプリカ・全業務機能の証明とは区別する。
