# 独立コメント入力UIの接続段階

要件F07・U05・U06・D04・T02に対応する入力段階。採用mockの最終モーダルを、明示実認証モードの保存済みイベント参照へ接続する。固定171資産と適用済みモデル／migrationは変更しない。

## 入口と読み取り契約

イベントの「コメントのみ投稿」から独立したモーダルを開く。参加枠の選択・設問回答を読み取って送信する経路とは分ける。

既存の認可済みイベント詳細DTOへ`canComment`を追加した。サーバーが現在の認証失効・DBの全体／当該担当権限・イベント閲覧可否と同じsnapshotで求める入力入口用のヒントであり、投稿許可の証明ではない。一般ユーザーは日本時間の開催日の終わりまで、管理者は期限例外。翌日00:00:00の境界を拒否し、UTCの日付で判定しない。開く直前にも再取得する。失敗・不正DTO・対象不一致・401では前の本文を入力欄へ表示しない。画面移動・閉鎖後の遅延応答を破棄する。

## 未送信本文と取消

コメント名・必須表示・外部日本語JSONの説明・textarea・主要ボタンは固定mockへ揃える。trim後3文字未満の入力を不正とする。改行とHTML風の文字列をそのまま入力値として扱い、HTMLとして解釈しない。説明JSONが不正・null・通信失敗でも未取得を案内し、開き直しで再取得する。

- ×／Escape：同じ文書・本人・イベントに限り本文をメモリへ保持し、開き直しで戻す。
- 明示キャンセル：そのイベントの未送信本文だけを破棄する。
- 背景操作：閉じない。本文を失わない。
- 同じ本人の別イベントへ移動：別の本文を混ぜず、それぞれのメモリ下書きを保持する。
- 認証消失／本人変更／pagehide：メモリ下書きをすべて破棄する。再読込・タブ終了後の復旧を保証しない。

localStorage／sessionStorage／Cookieへ本文を保存しない。プロフィール編集の取消と異なる意味を維持し、一律のモーダル閉鎖へ戻さない。Tab／Shift+Tabを周回し、閉じた後は起点へ戻す。開いている間の定期取得やwindow focusで本文を上書きしない。低い画面では内部スクロールする。

## 未接続の境界

**投稿保存は未接続**。主要な「コメントを投稿」ボタンを無効にして明記する。偽の投稿成功・トースト・ローカル保存・コメント一覧への模擬追加は行わない。保存モデル・migration・業務APIへ書込みを追加しない。

後続の保存接続では、現在認証／Origin／CSRF／閲覧権限／期限／trim入力をサーバーのトランザクション内で検証する。D02の操作IDと本人・イベント・用途・要求内容の束縛、同一要求の元結果、別内容拒否、削除後の再送で復活しないこと、監査・結果不明・再取得を扱う。現在の`canComment`だけを信用して保存しない。

既定公開配置はdemoのまま。実volume・DB・鍵・秘密設定を変更しない。入力UIの公開・自動照合を、全UI完成・投稿保存完成・全実機受入へ拡張しない。

## 検証

合成HTTPSの集中回帰：初期値・trim・改行・エスケープ、背景非閉鎖、×／Escape保持、明示キャンセル破棄、イベント分離、フォーカス周回／復帰、window focus、再読込、401、404、503、不正受付ヒント・対象・遅延。POSTがなく保存済み参照が不変であることを確認する。

同一データの固定mockと320／390／768／1440px×ライト／ダークで主要スタイル・項目名と必須を比較する。説明量の異なる段階版注記によるモーダルの高さを同一と偽らず、中央配置・画面内収容・内部スクロールを別に検査する。両者のフォーカス・ホバー状態を合わせ、`:focus`背景差と自動中央配置の算出marginをレイアウト不具合と混同しない。

全接続回帰では参照UI一式の後、既存のDB・鍵・Cookie維持の再起動検査を行い、プロフィール・コメントの入力を実行する。人工的な大量画面移動で前の検査が読取180件／分を使い切り、後続UIを偽の通信障害へ巻き込むことを避ける。製品の制限値・検査対象・必須工程・時間上限は緩めず、全検査を実行し、コメント集中中と全体の429が0件であることもassertする。
