# 個人表示設定UI：選択・プレビュー・取消の接続段階

要件F12・U02・U05・T02に対応する。保存済み設定の参照・適用（PR141）とは別のUI接続段階であり、適用保存・カタログ編集の完了ではない。

## 固定mockとの対応

採用固定版の補助メニュー `#appearance` と「あなたの表示設定」中央dialog、`form-grid` 内の配色・明るさselect、適用・キャンセルを使用する。固定171資産は変更しない。既定10テーマの順序はForest／Ocean／Plum／Amber／Rose／Teal／Slate／Midnight／Coral／Monochrome。カスタム候補は後ろへID順に追加する。名前はDB値を文字として表示する。

固定mock最終装飾の任意バッジと外部日本語JSONの項目ヘルプも保持する。ヘルプはdialogより前面に表示し、閉じた後には残さない。

デモ操作の区画名・ユーザー切替は持ち込まない。補助区画を「表示設定」とし、保存が未接続である説明を追加して適用を無効にする。この2点は製品固有の意図した差分。模擬保存・成功トースト・Web Storageへの設定保存は提供しない。

## 読取契約

- `GET /api/ui/appearance/editor`：現在本人の個人選択、選択候補、本人＋サイトの確定表示、個人値を除いた継承表示。
- `GET /api/ui/events/{id}/appearance/editor`：同様に、現在閲覧可能な対象イベントを継承表示に含める。
- 本人・stamp・session・現在の管理権限・実効フェーズを同一読取snapshotで確認する。別ユーザー指定、query、本文、非GETを受け付けない。非公開担当外と欠損は同じ404。匿名／失効は401。
- 通常の配色参照は選択結果だけを返すまま。編集入口だけにテーマ名／候補と現在の個人選択を追加する。メール・認証情報・カタログ版・他人の選択は含めない。
- 色は長さ7のhexだけ。欠損参照、不正モード、不正候補を黙って除外・既定化しない。候補は最大1024、ID128文字・名前256文字の安全上限を超える場合は422とし、不完全な一覧を選択可能にしない。
- 読取によりDB／WAL・cache・監査を変更しない。モデル・migrationは変更しない。

## プレビューと取消

色とモードは独立に選べる。「既定設定に従う」はその項目だけ個人値を除き、現在イベント→サイト→既定へ戻す。明示systemは端末設定に追従する。固定mockと同じ最終色計算を再利用する。

選択変更はメモリだけに適用する。キャンセル・×・Escape・背景で、開いた時に取得した確定表示へ復帰する。閉じるイベントの処理完了後にフォーカスをメニューへ戻す。Enterで保存・暗黙確定しない。保存配色の再取得中は入口ボタンを無効にし、表示後に有効化する。外部ウィンドウからfocusが戻っても開いているdialogを再取得で破棄しない。

世代・本人・対象イベントが異なる応答、画面移動後の応答、閉じた後の応答は使わない。401では旧本人表示・色を消す。失敗・不正DTOでは候補を出さず、閉じて再度開く案内とし、偽の空設定として扱わない。ページ離脱では個人配色・プレビューを破棄する。

## 検証と残り

合成DBの読取・継承・現在認可・DB／WAL不変、実製品HTTPSの候補APIと最終mockの4幅×明暗でdialog／selectの寸法・字体・色・余白・候補順を比較する。取消、Escape、背景、低い画面、個人／継承、失効、失敗、不正値、遅延、HTML文字列を検査する。集中実行と全接続回帰は別に記録する。

適用保存は後続。現在認証・Origin／CSRF・版・同一操作ID／結果不明・再取得を含む保存契約なしに適用を有効化しない。全UI完成、ユーザー実機受入、実認証の公開有効化を意味しない。
