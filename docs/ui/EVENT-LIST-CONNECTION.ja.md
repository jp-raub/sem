# 固定モックのイベント一覧と保存データの接続

## 対象

明示した `SEM_APPLICATION_MODE=authenticated` だけで、既存アカウントのパスキーログイン後に保存済みイベント一覧を参照する。既定demo、固定mock171資産、既存77型・43 migrationは変更しない。配置・起動保全は [製品接続](../auth/PRODUCT-CONNECTION.ja.md) と同じ。

一覧は全UI接続の一段階であり、イベント詳細・作成・プロフィール・参加登録・保存・招待登録・メール・復旧は未接続。詳細リンクは未接続を案内し、全体管理者の新規作成ボタンも無効とする。模擬保存・架空イベント・デモのロール選択を実機能へ混ぜない。公開既定配置を実volumeへ切り替える作業は含めない。

招待・アカウントの安全な接続にはメールと途中状態の限定権限をまとめて扱う必要がある。単独コピーで保護を落とす代わりに、既存認証で参照可能な一覧を先に接続する。これは独立したバックエンド機能の先行実装ではない。

## 読取APIと保護

`GET /api/ui/events` はqueryを拒否し、非GETで変更しない。HTTPS／Host／毎要求のCookie検証／no-store／共有レート制限を継承する。さらにdeferred SQLite読取transaction内で、本人・メール確認・有効性・stamp・失効session・現DB管理者・担当イベント・有効フェーズ・枠数を同じsnapshotから読む。claimの管理者ロールを信用しない。

- 全体管理者は全イベント、その他は有効フェーズが非公開でないイベントと本人担当の非公開イベントだけを返す。
- 手動指定は一意な有効行を採用。自動判定は開始を含み終了を含まないCustom期間のうち最新開始→表示順→ID、該当なしは開催時刻以降View、それ以前Hidden。比較はISO文字列順でなく絶対時刻。timezone未指定・不正期間・不正上限・欠落／重複フェーズ等は推測せず当該イベントを除外する。
- `SessionEvent.PhaseKind` cacheは開示判断に使用しない。参照でcache、IsActive、監査、取込保護履歴を変更しない。今後の書込処理はフェーズと権限を改めて検証し、一覧の結果を保存許可として流用しない。
- DTOはサービス名、イベントID／題名／場所／UTC日時／フェーズ／上限／お知らせ、空き・全体・本人の枠数だけ。説明本文、メール、管理者ID、他人の割当ID、非公開回答、鍵は含めない。
- 枠数は同イベントの有効曲・有効パート定義・有効な曲タイムパートがある実枠を数える。削除済み定義は除外。互換上存在する同種別の複数枠は別枠として数え、人数・曲数の上限と混同しない。

## 採用UI

最終mockの見出し、3指標、5列、phase badge、table-wrap、題名／開催日時ソート・ARIA・並び順表示を接続する。初期は開催日時降順、題名は日本語照合、同順位はIDで安定化。3指標は閲覧可能なイベント件数、Customかつ上限0以外の受付中件数（-1を含む）、本人の登録枠数。時刻表示はブラウザーのtimezoneに依存せずAsia/Tokyo。

題名・場所・お知らせ・サイト名等は文字として挿入し、HTMLを実行しない。認証・一覧データをWebStorageへ保存しない。遷移・再取得・ログアウト・pagehideでは以前の表示を消し、世代番号とabortで遅延応答の混入を防ぐ。401は再ログイン、通信／形式不良は明示再試行、正常な空一覧は空状態とし、失敗を空結果に変換しない。1MiB超の一覧応答はクライアントの安全上限として明示失敗にし、件数を黙って切り捨てない。これは製品のイベント数上限ではなく、大規模件数の性能保証は未測定。

保存済みテーマ、メニュー全項目、全モーダルの接続は後続。共通CSS採用だけで全UI完成とはしない。

## 集中検証

- `dotnet run --project tests/Sem.EventList.Checks -c Release`：合成DB・現ロール・担当解除・失効・時刻境界・最小DTO・原DB非変更。
- `scripts/product-authentication-browser.cjs`：標準の仮想パスキーで実製品へログインし、一覧・指標・ソート・XSS負例・読取拒否・失敗／空／再試行・ログアウト・再起動・起動保全を検証。4幅×ライト／ダークで固定mockの最終一覧スタイルと骨格を比較する。異なるソート状態の比較で停止した初期試行は成功へ流用せず、同じ状態に揃えて再実行する。
- fixture専用の `SEM_EVENT_LIST_FIXTURE=1` はtestsホストだけで使用し、製品には含めない。
- 既存の標準認証・保存保持・配置保全・固定画面基準と版／公開照合は維持。物理認証器、全replica、全業務機能の証明は別。
