# UI MOCK v16：PC幅・所要時間整列・統合アカウント管理

- PCページ幅は最大1920px、左右24px。1500px以下では参加入力を表の下へ回し、表を広く表示する。
- 所要時間も右寄せ・等幅数字。
- アカウント一覧へ権限、認証状態、サンプルキー数を統合。独立した認証状態/復旧枠は廃止。
- 表示名クリックで確認モーダル。サービス設定編集モードでは表示名・読み方・呼称・全体管理者権限を下書き編集。保存/取消は従来どおり。
- 認証メールは読み取り専用、特権権限は解除不可、イベント限定権限はイベント側設定。
- 復旧は同モーダルから従来の理由/再認証確認へ。サービス編集中は開始できない。実認証やメール送信は行わない。
- 通知メールの文面プレビューもアカウント枠へ移動。

## 検証

新規21項目、イベント機能30項目、参加登録21項目、計72項目成功。1920px/1366pxのサンプルタイムテーブルと390pxのアカウント画面を確認。多数列・小画面では内部横スクロールを維持。
