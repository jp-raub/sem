# UI MOCK v27：イベント内タブの選択保持とタブ外観

イベント/参加者名簿/受付/当日進行/通知の選択をイベント・ユーザー単位で記憶し、同じブラウザタブの再読み込みやイベント間往復で復元。選択状態のみsessionStorageへ保存し、イベントデータや権限は変更しない。

- 初回はイベントを表示。権限・開催日などにより現在利用できない保存タブはイベントへフォールバック。
- 独立ボタン風ではなく、上側角丸と内容背景に接続する下辺をもつタブ形状へ。選択中は上辺アクセントと太字で明示。
- スマホは横スクロール。左右キー/Home/Endによる選択とフォーカス移動、タブ/パネル相互のアクセシビリティラベル、選択タブだけのTabキー移動を追加。
- 他ユーザーの管理者タブを継承しない。権限がないパネルは記憶によって生成しない。
