# UI MOCK v12：入力・編集・プロフィールの操作改善

2026-10-11 04:36の依頼を反映。

- 日時入力のカレンダーボタンを入力枠内の右端へ配置。yyyy/MM/dd HH:mmの書式と既存の日付選択処理を維持。ネイティブメニュー未対応時の代替入力は引き続き使用可能。
- 入力説明を最前面の浮動表示へ変更。対応ブラウザではnative popoverをモーダルより後のtop layerに配置し、単なるz-indexでは解決しないモーダルの重なりとクリップを回避。未対応時は開いているdialog内へ配置。ホバー終了/フォーカス解除/Escape/スクロール/モーダル終了で閉じ、タッチはタップで表示する。
- コメントのみ投稿ボタンをコメント枠の最下部・右寄せへ移動。専用モーダル・投稿期限・選択中の参加枠を登録しない動作は維持。
- 管理者の編集モードでは曲名/進行名クリックで編集モーダルを表示。Enter/Spaceも使用可能。表内の情報編集・削除ボタンを取り除き、削除ボタンをモーダル内に移動。登録者がいる曲の削除理由と最後の保存で確定する方式を維持。
- ドラッグによる並び替えを維持し、ドラッグ直後のクリックを抑止。上下ボタンは代替操作として維持。
- 自分のプロフィールで絵文字または画像アイコンを指定可能。PNG/JPEG/WebPは10MBまで選択可能、中央の正方形を192×192へ縮小して保存。既定に戻す、保存前プレビュー、キャンセルが可能。画像はデータURLに限定しSVGや外部URLを受け付けない。
- アイコンは詳細プロフィール、登録者のコンパクトなプロフィール、既存の公開条件を満たすQRプロフィールで表示。プロフィールと同じ公開範囲。メールや招待情報は追加しない。
