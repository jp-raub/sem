# UI MOCK v21：演奏保護・準備継承・参加者/管理者表示

## 確定仕様
- 演奏時間は短縮不可。曲の長さを当日の見積でも保護し、演奏の短縮設定を除去。旧演奏短縮見積は新計算で採用しない。記録済みの実績終了は保持。
- 曲追加・計画編集・当日の準備入力は、イベント既定値をプレイスホルダーとして表示。空欄は既定値を継承し、入力時のみ個別指定。0:00は準備なし。クリアで継承へ戻る。既定値はコピー保存しない。
- 短縮案を承認して準備を短縮する場合は、その日の個別指定に切替える。巻きは許可された未開始の準備/進行時間だけ。
- 一般参加者：オンスケ/ビハインド（遅れ時間）、現在の状態、次のパートと開始見込み、本人の未完了登録曲。管理操作や予実表/監査を出さない。
- 管理者：参加者表示/管理者表示を切替。管理者表示には単一の記録ボタン、予実表、当日見積、承認式の短縮提案を維持。
- 現在の実績と元の予定を比較し、未開始/記録待ちの遅れも表示。将来の短縮で終了予測が回復しても現在の遅れをオンスケに偽装しない。

## 確認
管理者でイベントを開き、当日をプレビュー/日時指定→当日進行。表示切替で参加者視点を確認。一般ユーザーへ切替えると参加者表示のみになる。
