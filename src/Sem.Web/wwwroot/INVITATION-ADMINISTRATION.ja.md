# UI MOCK v33：招待リンクの権限とサービス管理

## 権限
- 全体管理者：招待管理に直接発行と依頼の確認・許可／拒否を表示。自身の発行リクエスト操作は表示しない。
- イベント管理者・一般ユーザー：発行リクエストと自分のリンク確認のみ。直接発行・承認・緊急失効の権限は付与しない。
- 直接発行：目的・人数・期間を指定して即時発行。依頼レコードは作成せず、直接発行の区分と発行者を記録。人数・期限による失効は承認されたリンクと同じ。

## サービス管理の一覧
リンク、発行方式、リクエスト元、承認／発行者、登録人数／上限、発行日時、有効期限、状態、緊急失効操作を表示。リクエスト経由と管理者直接発行を区別。旧コードに人物記録がない場合は推測せず旧記録（不明）と表示する。

## 緊急失効
全体管理者が理由を入力し、追加確認後に即時失効。失効理由・操作者・日時を独立した永続記録へ保存し、通常編集の保存・取消、再読み込みにかかわらず新規登録を拒否する。登録済みユーザーには影響しない。サービス管理の通常編集中も緊急失効を実行できる。
