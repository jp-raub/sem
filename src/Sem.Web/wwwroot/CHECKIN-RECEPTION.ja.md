# UI MOCK v28：読取り記録とQRなし手動受付

有効な参加者QRを読み取った時刻・参加者・担当管理者を1読取り1件で保存。直近記録を参加者一覧、全記録をQR読取り履歴で確認。受付の取消や再読取りでも読取り履歴は残す。無効なQRは成功読取り記録を作らない。

受付完了は別に時刻・担当管理者・QR/手動の方法・受付メモを記録。QR完了は該当する読取り記録へ紐付け、読み取っただけでは完了扱いにしない。既存の記録は旧記録と明示し、過去の読取り時刻を推測で補わない。

表示名/プロフィールのReadingを部分一致検索。大文字小文字・全半角・ひらがな/カタカナを正規化。QRを発行せずに登録者を選択し、本人/申込状況と必要な受付対応を確認後、管理者が手動登録。観覧のみも対象。

参加登録/権限/編集モード/復旧モード/QR再発行を確認し、二重受付や更新競合を拒否。記録は共通デモ時計を使用。QR画像/実カメラ/他端末との共有は引き続き未実装。
