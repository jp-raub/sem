# UI MOCK v19：QR受付・当日進行・メッセージボックス

## 確認手順
1. イベント管理者/全体管理者でイベントを開く。通常の編集モードは保存/取消して終了する。
2. チェックインタブで参加者の模擬読取りを押し、名前/曲/パート/観覧を確認。受付対応チェック後に完了する。読取りだけでは完了しない。
3. 当日をプレビュー/日時指定で開催日の日時を入力すると当日進行タブを表示。準備→開始→終了の実績ボタンで進行を記録する。必要に応じてデモ時計を進める。
4. 当日見積・固定予定から準備/演奏時間と固定日時を設定。後続予測を再計算し、固定と重なる場合は警告。元のタイムテーブルは維持する。
5. 参加者への通知タブで任意通知を作成、件名のPushカードをプレビューして参加者のボックスへ保存する。
6. デモユーザーを参加者へ切替し、共通メニューのメッセージから本人宛の本文/既読を確認する。

## モック範囲
- 本人×イベントの模擬QRリンク。再発行で旧リンク無効。他イベント利用不可。画像はダミー、カメラ読取りなし。
- チェックイン重複防止・受付確認・運営監査。
- 当日のみの進行表示、明示的なデモ時計、実績/見積/固定/重なり警告。
- 直前パートの開始実績で次の曲の登録者へ準備通知を保存。
- 開催120分前と直前なしの準備10分前は、期限到来分を評価する模擬操作で確認。未送信予定は見積変更を反映し、既送信は重複させない。
- 任意通知は演奏/観覧を含むユニーク参加者ごとのメッセージ保存。本人宛のみ一覧・本文・既読。
- 運営状態は通常の下書きと別保存。通常編集中は運営書込み不可。

カメラ、読み取れるQR画像、端末間同期、実Push・メール、バックグラウンド予約、サーバー認可・排他・監査の本番実装は含まない。
