# UI MOCK v29：閲覧モーダルの閉じる操作とイベント概要の並び

フッターがキャンセル/閉じるだけのモーダルは閉じる1つへ。編集/受付確認など変更を伴うモーダルではキャンセルを維持し、次のモーダルで表示状態をリセット。

概要編集は以下の順序。ペアは2カラム、その他は1カラム（スマホでもペア構成を保持）。

1. イベント名
2. 開場日時・開始日時
3. 場所・URL
4. イベントアイコン・参加人数上限
5. 概要（入力形式、本文、プレビューを同じグループ内）
6. お知らせ
7. ヘッダー画像（プレビュー/削除を含む）
8. 配色・明るさ

既存の入力要素を移動してカレンダー・プレビュー・画像・即時配色の動作を保持。イベントアイコンはテキスト/絵文字として下書き保存・取消・確定に対応し、イベント見出しへ反映。
