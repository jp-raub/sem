# UI MOCK v23：加速するデモ時計

## 操作
管理者でイベントを開き、当日をプレビュー／日時指定→日時を指定→再生。既定5倍速（実時間1秒＝デモ5秒）。1/5/10/30倍速を選択可能。一時停止、シークバー、基準点へ戻す、実際の時計へを用意。

- 進行のカウントダウン、オンスケ／ビハインド、実績記録、通知期限評価は進むデモ時刻を参照。
- 予定時刻を過ぎても実績は自動記録しない。通知評価は既存の明示操作を維持し、実配信は行わない。
- シークは一時停止する。登録済み実績は戻さず、逆転する時刻の記録を拒否する。イベントの予定日時は変更しない。
- 再読込後は保持した時刻で一時停止。速度を維持。実際の時計へ戻すとシミュレーションを解除。
- 操作は担当／全体管理者限定。通常編集中と復旧モードでは無効。参加者表示も同じブラウザのデモ時刻を参照する。
- これは動作確認用。認証期限、プロフィールQR期限、実メール・Push等を加速させる本番機能ではない。
