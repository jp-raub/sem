# UI MOCK v24：参加者の時間書式・管理者の記録点比較

## 参加者
残り時間は1分未満のみ秒、それ以外は分のみ（切上げ）。例：59秒→あと59秒、61秒→あと2分。
遅延はs秒またはm分ss秒。例：5秒遅れ中、1分05秒遅れ中、1分00秒遅れ中。

## 管理者
タイムパートでグループ化し、記録点を1行として当初計画/最新計画/実績を横に比較する。曲は準備開始・演奏開始・演奏終了、進行は進行開始・終了。
当初計画は事前の予定。最新計画は実績と当日見積を反映した時刻。実績は管理者の記録値で未登録なら未記録。変更された最新計画を強調。通常の参加用タイムテーブルは変更しない。
単一の記録ボタン、当日見積ボタン、時間保護と短縮承認、モバイルの記録優先を維持。
