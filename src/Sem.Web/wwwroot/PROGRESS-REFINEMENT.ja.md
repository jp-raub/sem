# UI MOCK v20：単一ボタン進行・承認式の巻き

- 当日進行を通常のタイムテーブル型へ。準備/演奏・進行開始/所要時間/終了/担当パートを1行にまとめ、予定/当日見積/実績を比較。
- 時刻を記録ボタンは1つ。現在の状態から次の操作を明示。終了は次パートの開始と同時刻に一括保存し、次が曲なら準備開始。次の押下で演奏開始。
- 実績境界は丸めず、最後の終了でイベント完了。連打、時刻逆転、古い状態や既存実績の上書きを保護。
- スマホでは現在/次操作/大きな記録ボタンを優先。予実表は明示表示。PC・タブレットでは予実表を既定表示。
- 事前行編集と当日見積に、準備と演奏/進行それぞれの短縮可否・最短時間を追加。既定は時間確保。時刻固定とは別の概念。
- 巻き・バッファ短縮は提案のみ。未開始の許可枠を順に下限まで提案し、管理者の確定後だけ当日見積へ反映。開始済み/保護枠/実績/元の予定を変更しない。残る遅れを表示。
- 15分休憩・最短5分・遅れ7分なら8分へ提案。表示や取消では反映しない。
- v19の実績は引継ぎ、旧時刻固定値は保持するが今回の連鎖計算には使わない。旧任意通知と新しい進行通知を本人用ボックスへ統合。
- 当日をプレビュー/日時指定で確認可能。実Push/カメラ/端末間同期/本番認可・排他は未実装。
