# v3.1: 枠状況・コメント期限

2026-10-10 最新回答を反映。

- イベント一覧の「現在のフェーズ」の直後に「枠状況」を1列追加。表示は空き枠数 / 全体枠数、例「5 / 10」。曲の演奏パート枠だけを数え、進行パートは除外。受付フェーズ・ユーザー上限による申込み可否とは別の数値。
- コメントの参加者受付はイベント実施日（ScheduledDate）の23:59:59まで、日本時間（Asia/Tokyo）。翌日00:00:00以降は無効。終了予定時刻やフェーズには連動しない。
- 全体管理者・対象イベント管理者は期限後も投稿可。無関係のイベントの管理権限は例外に含まない。
- 画面を開いたままでも期限でコメント欄を無効化し、送信処理でも再判定。コメント期限はパート申込みの受付を変更しない。
- ローカルChromium/Playwrightで15項目成功。qa/event-rules-results.jsonに結果。

今回の変更はこの2点のみ。直前に相談した日時書式統一とサービスプリセット／イベント別パート定義・Sing/Play分類はまだ未実装で、現状はv3の固定マスタのまま。
