# UI MOCK v25：横並び・遅延強調・即時テーマ

- 時間表記を準備m:ss／演奏m:ssの順へ。
- 状態タグと当日見積ボタンを横並びにし、各記録点の行高を72pxで統一。長いタイトルは省略し全体をツールチップに保持。
- 現在のパートは太い左境界・背景・タイトルで強調。遅延時には文章のアラートと遅延時間も表示。
- 各記録点の最新時刻と当初計画の差で警告色を段階化：1分未満は淡色、1分以上5分未満は中間、5分以上は濃色。現在の未記録点が最新予定を超えている場合も警告。
- 短縮/実績反映で追いつく記録点から通常色に戻す。将来の回復を理由に現在の遅延を消さない。
- テーマは選択後すぐプレビュー。適用で保存、取消で確定済みの配色に戻る。個人→イベント→サイトの優先順位、下書き保存/取消を維持。ダークでも遅延色と文字の可読性に配慮。
