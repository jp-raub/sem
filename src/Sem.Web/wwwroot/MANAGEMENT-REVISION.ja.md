# UI MOCK v7：管理画面・入力説明（2026-10-11）

## 入力説明

固定の入力項目に限り、項目名の後へ？を配置。管理者が定義したイベント/プロフィール設問、動的な演奏パート選択、全体管理者チェックには付けない。マウスではクリックしてもピン留めせず、カーソルが離れたら消去。タップでは開閉/外側タップ、キーボードではフォーカス/フォーカス解除・Escapeで表示を制御。

## イベント管理

管理編集時の左ペインは、フェーズ設定→タイムテーブル→観覧のみ申し込み→コメント→イベント設問→イベントの演奏パート定義→イベント限定管理者設定→監査ログ。

有効フェーズは一覧内のラジオ選択。選択は下書きで、最後の保存で確定する。既存の日時によるフェーズ再評価は保持。

イベント限定管理者はユーザー一覧を表示名/メールの部分一致でインクリメンタル検索し、表示名（メールアドレス）の候補から選択して追加。既存の対象イベント管理者/全体管理者による編集権限を保持。

監査ログは時刻・操作者・エンティティ・操作内容・詳細のテーブル。5行分の固定枠で縦スクロール。長い詳細は省略表示しホバーで全文確認。新規ログに操作者Idも記録。これはモックの表示確認用で、改ざん防止保証のある本番監査ではない。

## サービス管理

特権列は削除し表示名に「特権アカウント」タグ。特権ユーザーの全体管理者解除禁止は保持。

「演奏パートのプリセット」に改題し追加ボタンを強調。プリセットとプロフィール設問はグリップのドラッグで並び替え。従来の上下ボタンもキーボード/端末向け代替として保持。並び替えは下書きで、既存イベントのプリセットコピーには影響しない。

サイトテーマは常時メニュー表示し、非編集時は無効。編集時は選択が下書きに反映され、最後の保存で確定。

招待リンクの発行ボタンを発行済招待コードのセクションへ移動。無効化は確認後に下書きへ反映し、保存後は既存リンクでの登録も拒否。無効化日時/操作者を記録し、登録済みユーザーには影響しない。
